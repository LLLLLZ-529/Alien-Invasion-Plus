# Alien Invasion Plus 🚀  
基于 pygame 的《外星人入侵》增强版（含 Boss、护盾、掉落、音效等多项扩展）

本项目在《Python 编程：从入门到实践》的基础游戏上进行了大幅扩展：  
新增 Boss 战、外星人子弹、护盾、加血掉落、长按自动射击、关卡系统、最高分记录等功能，使整体玩法更接近真正的街机射击游戏。

---

## 🌟 游戏特色（新增内容）
### 🆕 **1. 外星人发射子弹**
- 外星人具有独立攻击频率
- 子弹朝玩家方向发射
- 击中玩家则扣血

### 🆕 **2. 三关一 Boss 的关卡系统**
- 普通关卡逐渐提升难度
- 每第 4 关进入 Boss 战
- Boss 拥有生命条及特殊攻击模式

### 🆕 **3. 随机掉落系统（强化 + 回血）**
- 消灭外星人后有概率掉落：
  - 加血包（恢复生命）
  - 护盾（短暂无敌 或 一次抵消伤害）
- 玩家碰触即可拾取

### 🆕 **4. 护盾系统（Shield）**
- 护盾可吸收一次敌方攻击
- 护盾可在特效下闪光提示

### 🆕 **5. 长按空格连续发射子弹**
- 按住空格可自动连射
- 具有射速上限，避免无限刷性能

### 🆕 **6. 游戏音效（sounds/）**
- 射击音效
- 爆炸音效
- 撞击与受击反馈音效
- Boss 主题音效（可选）

### 🆕 **7. Game Over 页面**
- 显示最终得分与最高分
- 支持重新开始

### 🆕 **8. 最高分持久化（高分不丢失）**
- 使用 `high_score.txt` 保存最高分
- 游戏退出后分数依旧保留

## 🎮 操作说明

| 操作        | 按键         |
|-------------|--------------|
